# 中国社会百态档案

一个按月整理、长期维护的中国社会事件档案，时间范围自 1995 年起。

## 目录

```text
archive/
└── YYYY/
    └── YYYY-MM.md
```

每个月原则上收录 3–5 个具有长期记录价值的事件。没有足够可靠材料时，宁可少收，也不以未经核实的信息补齐数量。

## 收录字段

每条记录至少包含：

- **标题**：中性、可检索的事件名称
- **描述**：已核实的事实经过；区分事实、媒体转述与尚无定论的说法
- **历史意义**：解释事件所反映的制度、社会、技术或公共治理变化
- **新闻链接**：优先使用政府通报、法院文书、主流媒体和可靠的长期链接

## 编辑原则

1. **证据优先**：不以社交媒体热度代替事实核验。
2. **事实与推断分离**：尤其是涉及死亡、犯罪、网暴和公共安全的事件。
3. **保留不确定性**：结论有争议或后续反转时，明确记录来源、时间和状态。
4. **按事件发生月归档**：若事件跨月发展，放在首次形成公共影响或关键结论出现的月份，并在描述中补充后续。
5. **可修订**：出现更可靠的新证据时，更新原条目并说明变化。

## 覆盖进度

档案正在从 1995 年开始按月回填，并持续更新到当前月份。月末任务负责追加当月条目；历史回填采用分批核验、分批提交的方式推进。

## 免责声明

本项目用于公共事件的历史整理与研究，不构成对个人或机构的法律定性。涉及指控的内容以可核验来源为准；若权威结论发生变化，应同步修订。
